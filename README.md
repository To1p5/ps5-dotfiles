# PS5 Bare-Metal Arch Linux (Sway) Dotfiles

Configuration files and keyboard-driven productivity scripts for Arch Linux running on the Sony PlayStation 5 (Oberon APU).

## Features
- **Sway:** Customized tiling window manager with Wayland acceleration.
- **Brave Browser:** Native Wayland launcher (`Super + Shift + B`).
- **File Managers:** Yazi TUI (`Super + Shift + E`) and Thunar GUI (`Super + E`).
- **Screenshots:** Window snip (`Super + Alt + P`), full screen (`Super + P`), and mouse freeze (`Super + Shift + S`).
- **Cheat Sheet:** Built-in floating shortcut guide (`Super + /` or `Ctrl + Super + Space`).
